# 🎥 YouTube Web Interface Clone

A responsive, pixel-perfect front-end clone of the YouTube home page interface built using pure HTML5 and CSS3. This project focuses strictly on replicating the visual layout, structural design, and interactive UI components of YouTube without video playback functionality.

---

## 🚀 Features
* **Header Navigation:** Replicated top search bar, voice search icon, user profile controls, and action buttons.
* **Collapsible Sidebar:** Functional sidebar layout displaying navigation categories, subscriptions, and library shortcuts.
* **Video Grid Layout:** Responsive video card layout featuring video thumbnails, channel avatars, video titles, views, and upload timestamps.
* **Hover Effects:** Smooth transition animations on interactive buttons, sidebar links, and video cards.
* **Fully Responsive:** Layout scales cleanly across varying screen sizes and viewport widths.

---

## 🛠️ Tech Stack
* **HTML5:** Semantic structural markup.
* **CSS3:** Custom Flexbox, CSS Grid layouts, and styling transitions.
